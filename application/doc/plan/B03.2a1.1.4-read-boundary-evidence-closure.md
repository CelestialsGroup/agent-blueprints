   不猜测状态码、不修改 Contract、不把现有通用路由行为算作合格证据；在最终 evidence 中继续
   machine-readable `blocked`；

facts 闭合，则停止代码范围。B03.2a2 Go adapter、B03.2b 平台 authority 和 B03.2c Safety

- 精确合法的 `GET /v1/runs/{runtime_run_id}` Status route；
- 精确合法的 `GET /v1/runs/{runtime_run_id}/events` Event route；

## Rollback 和 Data Retention

- Read route/mapper/encoder/tests 在不影响 durable facts 时可代码回滚；回滚不删除或重写
  Provider-local Run、JTI、Command、Event、work 或 checkpoint。
- 本切片不新增 migration；一旦发现需要 DDL，立即停止并单独审计。
- data-bearing SQLite v2 继续 forward-only。未经旧 binary 精确读兼容证据，不得二进制降级；
  只能前向修复。
- Event retention 已删除的旧 Event 不能由 rollback 伪造恢复；checkpoint object/manifest 引用关系
  保持既有规则，不能为测试或回滚删除已引用内容。
- read token/JTI 不持久化；测试 PKI/private keys、SQLite state 和 sockets 仅在临时目录存在，
  测试结束销毁。
- ignored build/evidence 可重新生成或移除，但删除 artifact 不是 durable data rollback；任何再生成
  都必须重新绑定完整 source/log/artifact digest。
