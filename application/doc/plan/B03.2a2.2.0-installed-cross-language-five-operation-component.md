   installed wheel/process、Ed25519 PKI、mandatory mTLS、HTTP/1.1、socket 与 Provider-local

## Scope

本切片只实现和证明：

- 一个 test-only Go component/integration harness 构造现有 `httpadapter.Adapter`；
- 在固定 Go toolchain 中编译 normal/Race test binary，再在固定 Python/uv toolchain 容器中
  安装并执行真实 wheel；Provider import 必须解析到 installed site-packages，不得解析到
  `runtime/native/src`；

  的 `open_current` 启动进程；
- 每次测试生成真实 Ed25519 CA、server/client leaf certificate、clientAuth EKU、server SAN、
  caller URI SAN、临时 invocation signing key 与 verification public key；mandatory mTLS、TLS
  >=1.2、ALPN/HTTP/1.1 和真实 loopback socket 不得替换；

  evidence 分别记录 Registry 资源文件 SHA 与内部 digest，不把二者混用；
- 五操作 happy path：Capabilities 无 bearer，Start/Command 各一次 dispatch，Status/Event 使用
  各自 bounded bearer；success response 必须通过锁定 Schema/Registry、ProviderRevision、
  RuntimeRun、invocation、fencing、event order/cursor 绑定；

- focused normal/Race 动态 markers、独立 evidence、source manifest、cache/sensitive scan、
  supply-chain binding 和完整 Application Gate/source-rebind。
